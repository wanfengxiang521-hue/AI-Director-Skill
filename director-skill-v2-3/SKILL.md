# 导演 Skill V2.3

版本：2.3。技能调用名为 `director-skill-v2-2`；合同族仍为 `DIRECTOR_LOCK v1`，输出使用 Codex 兼容结构 1.3。

## 任务边界

把一句话创作意图、锁定脚本、分镜要求或表达简报转换为连贯、可执行、可调整、可验收的导演设计；不承诺一句话直接产生完美成片。

本 Skill 决定观众如何被画面带动、人物和物体如何行动、空间关系如何变化、摄影机为什么移动、光色和声音何时改变、镜头在哪里结束。它可以丰富可观察的导演表达，但不得在未经授权时新增、删减或改写剧情事实、人物关系、事件顺序、结局及对白含义。

本 Skill 不选择生成模型模式，不创建平台标签，不绑定虚构素材，也不得输出任何模型的最终提示词。用户只要最终提示词且尚无导演锁时，先生成内部 `DIRECTOR_LOCK v1`，再交给 `$prompt-skill-v3-2` 编译。

若用户明确要求改剧情、开发故事或改文案，依据其授权范围建立新的事实锁；导演决定不能偷渡成剧情改写。现有授权持续有效，常规导演选择自行完成，不为内部检查重复请求确认。

## 输入与事实锁

先判断输入模式；已锁定的事实优先于输入长短：

- `ONE_LINE_INTENT`：一句意义、主题、感受或创作命题，尚无完整锁定剧情。读取 [one-line-intent.md](references/one-line-intent.md)；推导的人物、场景和事件明确写为导演提案，不当作用户事实。
- `LOCKED_SCRIPT`：已有锁定脚本、对白或事件顺序，逐项冻结不可改变事实。即使只有“她打开门，却决定不走”一句，也只补导演执行；原因、身份、关系、前史与代价未给定时保持未知，不按主题扩写。
- `SHOT_BRIEF`：已有镜头职责或分镜，只补足导演执行，不改镜头事实。
- `EXPRESSION_BRIEF`：较完整的主题、情绪或观众目标简报，建立最小简报锁，并区分导演提案与用户事实。

优先从当前输入与可读源文件核对目标时长、画幅、观众、传达意图、人物/场景/产品真值、锁定对白、必须保留项、禁止项、参考素材职责及允许改变的范围。信息缺失但不改变事实时声明最小假设；缺失项会改变剧情、人物身份、产品事实、商业证据、合规边界或授权范围时，先完成独立部分，再请求最小必要信息。

## 导演工作流

主线是：`具体感受/问题 → 可感知的关系 → 行为或视听组织 → 观察位置与信息范围 → 声音与剪辑完成感受`。后一步落实前一步；执行不成立时回改导演选择。以下为思考顺序，不要求逐项向用户朗读；简短概念和执行型单镜按实际需要压缩。

### 1. 意义层：解释原句并建立授权边界

保留原句或简报的判断，写清观众 `audience_state_A → 通过什么可感知变化 → audience_state_B`。例如“旁观忙碌 → 认出人物正在失去控制”，不用“高级、治愈、有感染力、电影感”等结果词代替决定。声音主导时，变化可以来自声音与稳定画面的关系。

找当前简报支持的表达支点：人物场景找目标与阻力，产品演示找需要看清的结构或接触，感官/意象场景找观看与聆听的组织关系，不替纯产品镜虚构人物冲突。每镜标明信息、情绪、关系、感官体验、联想或证据任务；允许延续氛围、延迟理解、开放意义和感受加深，不强求每镜新增事实或证明功效。

`ONE_LINE_INTENT` 按其参考建立最小意义合同：原句与命题、主体、当下目标、阻力、获授权的可观察取舍，以及意义边界和导演自由度。`cost` 缺依据时写未知/未指定，不用创伤、动机或关系填空。可逆的创作选择自行形成提案，歧义触及事实锁时才澄清。

商业主张先建立 `commercial_contract`：逐条区分公司、品牌、产品系列或单品并绑定证据范围。仅事实主张镜头声明 `proof_task`；情绪/联想镜声明 `expression_task`。各镜写观众可能得出的结论，规模镜头不得把公司总量暗示为单品数量。KOC 插片填写入口重音、口播区间、声音连续、退出触发和返回画框。

### 2. 终态层：最终证明画面与反向设计

先用一幅可停住的终态 `final_proof_image` 核对表达：人物、物体、空间关系最后在哪里，观众能确认什么，哪些意义依赖前面的声音。对照开场基线，找出使关系或感受改变的关键行为与声画组织。保留原有结局；执行型单镜只核对其已定终态，无需扩写故事。

这是一项短检查，不要求额外反转、运镜或事件。若观众无法感知预期变化，修复获授权的动作、空间或声画关系，不以解释字幕掩盖表达问题。声音主导方案的终态可由稳定画面与已发生的声音共同成立。

### 3. 规则层：锚点、行为词典与信息权限

**主视觉锚点**：整片和每镜分别确定一个服务表达的具体物体、动作、构图、光线、空间或状态反差，写清它如何进入、如何变化、停在什么可确认状态，以及带来的信息或感受。若删掉后表达完全不变，它只是装饰。

把抽象结果落到 `behavior_vocabulary`：可观察的动作、物理动词和状态差异，如松开、被阻挡、跨越、聚拢、留下；写出什么稳定、什么允许改变、变化顺序及哪次偏差改变判断。行为服务当前锚点与关系，不把门、镜子等符号当成表达，也不因缺少重复或第二条因果链而强造循环与背景事件。

按表达参考选择直接呈现、隐喻、局部代整体、对照、重复变奏、遮挡揭示、视点或声画对位。概念探索时内部比较两条表达逻辑不同的路径，选择一条并说明理由；用户已指定方式则直接深化，只要一个方案就交付选定方案。隐喻写清“表达对象→承载物/关系→共有结构→可见变化→期望联想→误读风险”，再落实到调度、摄影或声画决定，说明结束时如何保留或回收。单段优先一个主要对应关系，不强迫每镜隐喻或所有部门变化；演示与精确结构通常优先直观呈现，氛围也可由光声和观看时长成立。

一句话展开、人物认知变化、悬念揭示或声音依赖涉及谁先知道时，明确 `information_permission`：观众与人物各自能确认什么、仍未知什么、哪次可观察事件改变权限。观众看见不等于人物知道；未展示的动机与画外事件不写成事实，原因可以始终留白。纯结构展示无需虚构人物知识或心理。

### 4. 演出层：策略节拍、调度与视听执行

`ONE_LINE_INTENT` 的完整导演方案先列 **3–5 个策略节拍**，再展开逐镜与时码；相邻拍须有不同的策略或信息、关系、感受变化。锁定单一动作时用动作状态与信息范围划分，不为凑数新增事件；其他输入按其实际表达结构划分。策略拍不是切镜数，固定镜和声音主导段落也可承载多拍，不用机位变化伪造剧情。

**节拍定义**：每拍及其主要动作遵循 `START → MOTION → END`：`START` 是人物、道具、空间、光声的可观察起态；`MOTION` 是单一主要因果链、速率相位与接触响应；`END` 是可确认终态与停止条件，不能仅以“时间到了”结束。另写本拍新增的信息或感受 `audience_delta` 和 `visual_anchor`（沿用规则层定义）。复杂动作先拆节拍，再决定切镜。

先锁调度中的起止、主要移动、视线与距离权力变化。用任务、道具位置和空间条件引出行为，不因“画面需要”随意走位；动作依据获授权的目标、阻力或既定执行条件。实拍可在起止、事实与安全边界内保留反应差异；生成方案写明确的主要动作与终态，不把即兴解释成随机变化。重量通过受力和后果体现，只有表达需要时才设计失误。

**摄影执行字段**：观察者视点；机位位置/高度/朝向；景别、透视与机距；前中后景构图；运动方式/路径/触发/节奏/起止画框；焦点对象与转焦时机。每次运动说明信息、情绪、感官或联想依据，不限于跟随动作。固定镜写 `STATIC`、保持的画框与焦点及为何保持，不能用空白运镜代替。数值未测试时标为建议值或用相对尺度，不伪造器材实测。

摄影理由连接表达支点：从这里看能知道什么、暂不知道什么、与主体有什么关系；移动后改变什么，终框如何完成它。画外声音须核对声源路线与可见范围，不能使按路线必然入画的人物同时不可见。

光色显示时间、空间、身份、注意力或状态；声音区分环境底床、动作声、对白/口播、声音桥、静默和停止状态。保留“刺激到达 → 接收 → 行为变化”的可读时序；切点由动作完成、信息揭示、声音断点、视线或策略改变触发。对白须说明嘴部可见性、声源、口型、重音、停顿、呼吸及动作节拍，不改锁定原文。各轨可以稳定保持，声音也可承担全段叙事。

复杂调度、动作、特效、多人物、多镜头或多个生成单元时，把预演作为第一次剪辑：用合适的走位排演、简图、粗剪或 animatic 检查连接，移除不增加信息、压力、关系或感受且有权修改的节拍；锁定内容只报告冗余与冲突，不自行删除。简单单镜不强制制作 animatic。

### 5. 验收层：表达、时长、资源、连续性与静音检查

逐镜核对表达任务、锚点与节拍终态是否成立。必须做**静音观看检查**：关闭对白、旁白和音乐，检查核心状态、适用的人物目标/阻力/关系是否仍可读，列出仅由声音提供的信息；画面失效时修复动作、空间、锚点或终态，不增加解释字幕。结果记 `pass`、`partial` 或 `fail`；方案阶段写预判，只有看片才能写成片验收。声音主导或声画对位应说明静音后有意丢失什么，`partial` 不自动淘汰成立的视听表达。隐喻另查关联与主要误读，未经盲看不声称观众已经读懂。

按动作、锁定对白、摄影机运动、声音和不可并行转换核算最低时长；提示词字数不等于时长。冲突须报告，不能因时长压力改台词、事实、关系、顺序或结局，也不能压缩物理过程。

**资源与迁移边界**：区分导演方法与明星、特殊场地、昂贵机关、后期特效、大规模群演带来的资源效果；每套方案记录可迁移条件、不可迁移条件和最容易被表面模仿的部分。资源未确认时标为依赖，不宣称可执行条件已满足。

多页面/多产品需精确区分时，先有已核验的静态真值板及槽位→真实资产→版本映射；重复页面不能补足唯一数量。证明任务缺真实材料时完成独立导演部分，将依赖项标为 `blocked`，不用模型编造。

连续性核对人物身份、产品几何与包装、服化、道具状态、空间/屏幕方向、光声、动作起止和信息揭示顺序。每个生成单元继承上一单元的实际验收终态，不继承未经生成的想象状态。

## DIRECTOR_LOCK v1

正式合同或提示词编译交接使用 schema 中唯一的权威合同：包含事实与授权、观众变化和视觉命题、规则与节拍、表演调度及各视听轨与静音检查、时长证据、生成单元、连续性、资源风险、禁止项及唯一版本/ID。适用的一句话字段沿用上述定义；下游可以压缩语言，不能改变合同决定，导演层冲突须退回本 Skill 修正。

只有事实未变、时间轴可执行、每拍有终态、连续性完整且风险已显式记录，才写 `lock_status: locked`；否则写 `blocked` 并列冲突与最小修正。`lock_status` 不是 `locked` 时不得进入提示词编译。

## 输出规则

- 导演思路或 treatment：给表达目标、方法映射、关键画面/节拍、摄影策略、声音剪辑与取舍；摄影策略覆盖演出层的摄影字段，可用连贯文字，无需技术表。用户只要概念一句话时按要求缩短。
- 用“为何让观众这样感到/发现 → 画面与声画如何做到 → 停在哪里完成”的关系组织内容，将实际执行决定写入句子。简洁时压缩理论解释，保留执行决定，可用表格但不机械复读句式。
- 逐镜方案：每镜给时码与表达任务、节拍起止、演出层完整摄影字段、调度及光声剪辑；内容不能只在隐藏合同中。共享摄影可引用明确基线并写本镜差量。另给表达可读性与素材边界，未拍/未生成时标为方案判断。
- 普通思路和逐镜方案不附完整合同、不声称正式锁定。用户要正式合同才对外交付完整 `DIRECTOR_LOCK v1`；只要最终模型提示词时，按任务边界走内部锁与编译交接。
