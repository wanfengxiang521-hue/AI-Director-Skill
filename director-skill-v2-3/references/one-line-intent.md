# 一句话意图展开

## 适用条件与边界

适用于用户给出一句意义、主题、感受或创作命题，但尚未锁定完整剧情的导演任务。先保留原句的判断，再把角色、地点、事件和可观察选择写成**导演提案**；提案不是用户事实。若原句已是锁定剧情（如“她打开门，却决定不走”），把开门与留下视为不可改变的事件和结局，只补调度、观看范围与声画执行；原因、身份、关系、前史未知就保持未知。

沿用主 Skill 的事实锁、产品与商业主张边界、`STATIC` 固定镜、声音主导例外、静音 `partial` 判定和 `$prompt-skill-v3-2` 编译边界。这里建立导演设计，不承诺一句话直接产生完美成片。用户只要简短概念时压缩对外表达，内部仍核对事实与信息边界。

## 最小意义合同

以下字段是构思时的最小合同；正式交接仍使用 `DIRECTOR_LOCK v1`。一个字段只有缺资料时写“未知/未指定”，不以虚构事实填满格子。`cost` 指选择造成的可观察取舍；主题提案获得创作授权时可以提出，锁定剧情未给原因或代价时写“未知/未指定”，不能倒推出动机或创伤。

```yaml
original_sentence: "保留用户原句及其已锁定的事实"
central_proposition: "用自己的话说明原句要让观众理解或感到什么"
subject: "已给定的主体；否则标明导演提案或未知"
desire: "可观察的当下目标；锁定剧情未给时可写未知/未指定"
resistance: "与当下目标相抗的可见条件；未知时不虚构原因"
cost: "获授权时写选择的具体取舍；不获授权或缺依据时写未知/未指定"
audience_state_A: "开头观众会怎样理解或感受"
audience_state_B: "结束时观众理解或感受的变化"
final_proof_image: "可停住的终态画面，观众能从中确认的关系"
meaning_guardrail: "必须保留的原意、事实、产品与主张边界"
director_freedom: "可提案的人物、场景、事件及声画执行范围"
behavior_vocabulary: "可重复观察的动作选择、限制与状态差异"
information_permission: "观众与人物各自知道什么、暂不知道什么、何时改变"
```

先问谁正在做什么、想达成什么、眼前有什么阻力。若资料只允许执行层，目标可只写“打开门后身体停止向外移动”之类的行动，不替人物补心理原因。先确定观众状态 A→B；再选一个能发生变化的主视觉锚点和一个关系或物理动词。时长、画幅、场地、演员和测试情况分别标明已锁定、导演建议、资源依赖或尚未验证。

## 终态反推

写一幅可定格的终态：人物、物体、空间关系停在哪里，原句中的判断如何被画面或有意保留的声音支持。对照开场基线：同一锚点在最初是什么状态，观众为什么会作出状态 A 的判断。找出中间哪一次行为选择改变了关系；这可以是维持固定画面、等待、声音变化或一个接触响应，不要求运镜、反转或额外事件。若终态无法使原句变得可感知，调整提案中的行为或声画关系，而不是加解释字幕。这里只做短检查；详细摄影、时长与连续性仍按主 Skill 的相应参考执行。

在逐镜或时码前，先列 **3–5 个策略节拍**。每拍写“起态 → 人物或声画采取的策略 → 信息、关系或感受的变化 → 可确认终态”；相邻拍之间要有不同的策略或观众变化。策略拍不是切镜数：一个固定镜头或一个声音主导段落也可以承载多拍。若用户锁定单一动作，则用动作状态和信息范围划分，不添加剧情事件来凑数。

## 限制生成行为词典

把“自由、专业、孤独”等结果词落到能排演和核查的行为：手是否继续握住物体、脚是否跨过线、视线是否回到任务、动作是否完成、物体在接触后是否停稳。每个提案优先选一组与主锚点有关的可见动词及限制，例如“抓住—松开—仍能重新抓住”；写出什么保持不变，什么允许改变。词典服务这条片的关系，不是抽象情绪的固定符号表。不要把门、雨、镜子或慢镜头本身当成已完成的表达，也不强迫每个镜头都使用隐喻。

## 信息权限

逐拍区分：观众此刻能从画面或声音确认什么，人物能感知或知道什么，双方尚不知道什么；说明哪一次可观察事件改变权限。只有观众可得的信息，不能据此断定人物也知道；未展示的人物动机、背景和画外事件，不写成已经发生的事实。信息权限可以保持不对称，也可以始终不揭示“为什么”。声音主导时写清声音带来的新增信息，以及静音后有意丢失的信息；`partial` 是可成立的预判，成片是否奏效仍待观看验证。

## 歧义与最小澄清

一句话可有多种导演读法时，若它们只是可逆的创作选择，内部比较后选择一条，标明提案，不为风格偏好例行停下。缺失信息会改变已锁定事实、人物关系、产品真值、商业证据或授权范围时，先完成不依赖该信息的导演部分，再请求最小必要澄清。用户已有时长、无对白、固定镜或声音主导等限制时直接执行。对无法确定的代价、动机或观看验证状态，诚实标记未知或待测。

## 完整示例

用户原句：“真正的自由不是逃离，而是不再害怕留下。”用户要求三分钟无对白短片。原句、时长、无对白是锁定输入；以下人物、空间、道具和事件**全部是导演提案**，不是用户提供的剧情事实。

导演提案：一名成年人在一间空的排练室，门通向亮着灯的走廊；一把折椅和一个包在室内。她起初想带包走出门。可见阻力不是一个被编造的创伤或人物关系，而是每次停下来时她又想抓包离开。提案中的选择代价是：包已提起、门已打开时，她放下随手可带走的包，让本可立即跨出门槛的时间过去，出口始终开放；观众能看到她放弃了已准备好的离开动作。这是此方案的当下可见取舍，不宣称人物的既定前史或心理原因。

观众开头预计把开门和抓包读作即将离开；结尾能看到她仍可离开，却主动在室内坐稳。主锚点是**敞开的门与室内折椅的距离关系**，关系动词是“靠近出口—收回—安坐”。终态画面可停住：门仍开着，包仍可拿到，她坐在椅上，双脚留在室内，双手离开包；没有锁门、阻挡出口或外部人物替她作决定。反推开场，同一空间里她站在椅旁，手始终抓住包带，身体朝门倾，椅子空着。

| 策略拍（导演提案） | 可观察行为与终态 | 观众与人物的信息权限变化 |
| --- | --- | --- |
| 0–35 秒：预备离开 | 她把包提起、走向门；停在门边，椅子仍空。 | 观众只知道她正在准备离开，不知道原因；人物能看见出口可用。 |
| 35–75 秒：用离开结束停顿 | 她开门、手再抓紧包带，走廊声音进入；脚仍在室内。 | 观众确认离开的路径真的开放；人物同样能感知门已开。为什么要走仍留白。 |
| 75–125 秒：改变行动策略 | 她把包放回可拿的位置，走向椅子，中途回看开着的门；椅子第一次承受她的重量。 | 观众开始确认她不是被困住，而是在尝试留下；人物没有获得新的隐秘消息。 |
| 125–180 秒：保持选择 | 她坐稳，手从包移开，门始终开着；最后保留一段可读的安静。 | 观众确认“可以走但留下”；人物始终知道出口存在。动机和未来是否改变仍未知。 |

行为词典：抓紧包带、放下但不推远、向门倾身、回收重心、坐到椅面承重、双脚留在室内。摄影可从稳定的室内观察位让门和椅同框，只有确有信息增量时才改变机位；无对白不等于无声音，门声、包带摩擦、椅子受力和走廊底声给动作反馈。三分钟与各拍时长是导演排演建议，需现场验证动作最低时长及静止段的可读性。静音观看预计仍能读出“出口开放而她留下”，但没有拍摄和盲看，不写成已通过验收。资源假设为一名演员、一间有可用门的室内空间、一把椅和一个包；这些均非用户已确认资产。

## 验收

核对原句含义和已锁定事实是否保留，提案与用户事实是否分开；主体、目标、阻力和获授权的代价是否具体，未授权部分是否如实留空；观众 A→B、可定格终态及开场对照是否互相支撑；行为词典是否可排演；观众和人物各自的信息权限及改变时点是否写清；3–5 个策略拍是否有不同的信息或关系变化，且未把镜头数当拍数。最后核对产品、主张、声音、STATIC、时间、资源、连续性与测试状态；正式合同和最终提示词遵循主 Skill 的交接规则。
