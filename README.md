# AI 导演 Skill

同一仓库保留两个可独立安装的导演 Skill 版本。V2.2 是冻结的稳定基线；V2.3 是当前推荐版本，新增从一句话中心思想发展导演方案的完整入口。

## 版本选择

| 版本 | 调用名 | 适合场景 | 状态 |
| --- | --- | --- | --- |
| [V2.2](director-skill-v2-2/) | `$director-skill-v2-2` | 已有脚本、分镜或表达简报，需要调度、摄影、光声、剪辑及导演锁定 | 冻结，可直接安装与回退 |
| [V2.3](director-skill-v2-3/) | `$director-skill-v2-3` | 包含 V2.2 能力，并支持从一句中心思想、主题命题或创作意图发展完整导演方案 | 当前推荐版本 |

V2.3 增加 `ONE_LINE_INTENT`：先区分用户事实与导演提案，建立意义合同和授权边界，再由最终证明画面反推开场，形成主视觉锚点、行为词典、信息权限和 3–5 个策略节拍，最后落实到表演、调度、摄影、光色、声音、剪辑、时长、连续性与验收。

## 安装

只复制你要使用的完整版本目录到 Codex skills 目录，保留目录内部的 `SKILL.md`、`agents/` 和 `references/` 相对结构。通常的安装位置是 `~/.codex/skills/`。

安装 V2.2：

```text
~/.codex/skills/director-skill-v2-2/
```

安装 V2.3：

```text
~/.codex/skills/director-skill-v2-3/
```

两个版本可以同时安装，并分别通过 `$director-skill-v2-2` 和 `$director-skill-v2-3` 调用。不要把仓库根目录整体当作一个 Skill 安装，因为根目录只负责版本导航。

## 示例

V2.2：

> 使用 $director-skill-v2-2，为这个锁定脚本设计可执行的逐镜导演方案，不改变剧情事实。

V2.3：

> 使用 $director-skill-v2-3，把“真正的自由不是逃离，而是不再害怕留下”导演成一个三分钟无对白短片。

## 验证边界

两个版本分别执行 Skill 结构和内部引用检查。方法文档与方案级验证不代表实际视频生成、实拍可行性、观众理解或商业效果已经通过成片验收。

本仓库的版本拆分保留既有 Git 历史；V2.2 来自升级前的真实基线，不由 V2.3 反向改写。
